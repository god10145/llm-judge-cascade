# AI tools used in building this project

For transparency: this codebase was developed with assistance from AI tools.
This document records what was AI-assisted and what wasn't, so users can
calibrate their own trust appropriately.

## What was AI-assisted

- **Initial scaffolding (the 8 commits from initial repo through CI workflow):**
  Generated by Cursor Composer 2.5 from a detailed engineering brief written
  by the author. The brief specified file structure, the JudgeResult contract,
  cascade semantics, judge-prompt design, test coverage expectations, and
  acceptance criteria; Composer implemented to that spec.

- **The `KNOWN_ISSUES.md` cost-on-transport-error finding:** discovered during
  the first integration smoke-test against a real LiteLLM endpoint, with
  Claude (Opus 4.7) doing the failure-mode analysis.

- **Lint cleanup commit:** automated style fixes (typing imports,
  forward-reference quoting, PEP8 spacing) applied as a single sweep.

## What was not AI-assisted

- **The architectural decision** to use a cost-tiered cascade vs. a flat
  multi-model panel — author's design choice, motivated by cost-at-scale
  concerns when judging large rollout corpora.

- **Choice of MIT license, the package's positioning as domain-neutral
  infrastructure** (rather than tied to the author's specific test domain),
  and the API design contract.

- **Review and approval** of every commit, including the security pass for
  leaked credentials and the verification that the synthetic test dataset
  contains no domain-leaking content.

## Why disclose this

AI-assisted development sits in an awkward spot in 2026: there are real
projects done well with these tools, and there are projects whose AI
involvement is the most interesting thing about them. Disclosing up front
lets you decide which kind this is. The project's value (or lack thereof)
is in the cascade pattern, the cost model, and the working code — not in
the labor mix that produced them.

Bug reports, code review, and PRs are all welcome regardless of whether
the original author was human, AI, or a mix.
